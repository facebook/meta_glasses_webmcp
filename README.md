# Agentic Samples for Meta AI Glasses

Make a web app controllable by AI agents using
[WebMCP](https://developer.chrome.com/docs/ai/webmcp).

These examples demonstrate the capabilities agents have driving UX and
fulfilling user requests with voice control. Agents can take multiple steps to
drive complex behavior for glasses with a small display.

See the
[full documentation](https://wearables.developer.meta.com/docs/develop/webapps/agent-tools)
in the Wearables Developer Center on authoring applications with WebMCP for
Meta Ray-Ban Display.

Product guidance for building web apps for Meta Ray-Ban Display is published at
<https://wearables.developer.meta.com/docs/develop/webapps>.

## Examples

These are live samples you can try on Meta Ray-Ban Display. Scan the QR code
with your phone to install. Follow
[these instructions](https://wearables.developer.meta.com/docs/develop/webapps/setup/)
to turn on developer mode first.
