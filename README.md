# glasses_webmcp

Make a web app controllable by AI agents. This TypeScript library lets a page
register tools that an agent can discover and execute in the browser, with
imperative registration, declarative HTML forms, and React hooks.

The library is browser-generic. Its companion guidance covers running these
tools inside a web app on Meta Ray-Ban Display, where the agent calling them is
the assistant on the glasses.

## Documentation

Product guidance for building web apps for Meta Ray-Ban Display is published at
<https://wearables.developer.meta.com/docs/develop/webapps>.
